# Менеджер задач — Л4

Продолжение Л3 на React 19, Redux Toolkit, RTK Query и json-server 0.17.4. Интерфейс сохраняет CSS Modules, списки, карточки задач, подзадачи, фильтры, поиск с задержкой 300 мс, прямые ссылки и две темы.

[Макет To-Do List](https://www.figma.com/design/U09ssoBkhIpaSLmO5v0AQ7/To-Do-List-(Community))

## Запуск

Нужен Node.js 22.12 или новее. Из корня репозитория выполните:

```sh
npm install
npm run db:reset
npm run server
```

Во втором терминале запустите `npm run dev`. Vite покажет адрес приложения, API доступен на порту 3001. `db:reset` заменяет рабочую базу содержимым `server/db.seed.json`. Перезагрузите страницу, чтобы увидеть начальные данные.

Для случайных ошибок запустите `npm run server:chaos` вместо обычного сервера. 30% запросов записи получают ответ 500. Задержка по умолчанию составляет 400 мс. Для проверки при 1500 мс задайте `TODO_DELAY=1500` в окружении сервера, например `$env:TODO_DELAY = '1500'` в PowerShell. Адрес API задаётся через `VITE_API_URL`.

## Архитектура и решения

- [Карта API и команды](docs/api-map.md), [схема хранилища](docs/store.md), [маршруты](docs/routes.md) и [компоненты](docs/components.md).
- RTK Query хранит кеш списков и задач и управляет загрузкой, повтором и инвалидацией по тегам. Тема остаётся в контексте и localStorage. Поиск, меню и черновики форм живут в компонентах. Сохранение задач и перенос данных из localStorage уступили место серверной базе.
- Все операции с задачами и подзадачами, очистка выполненных и переименование списка оптимистичны и входят в историю. Создание списка и каскадное удаление списка ждут подтверждения сервера. Удаление списка убирает его команды из истории.
- История из 50 команд работает во всей вкладке, в том числе после перехода в другой список. Ctrl+Z и Ctrl+Shift+Z отправляют обратный и прямой запросы. В текстовых полях работают нативные сочетания. Блокировка сохраняется до ответа на запись и согласования кешей.
- Доступные уведомления сообщают об ошибке или результате отмены и повтора. После удаления задачи уведомление предлагает отменить именно эту команду, пока она верхняя в истории.

План с резервом — 15,12 ч. Фактические часы по этапам не фиксировались. При проверке отдельно разобраны откат кеша при ошибке и возврат фокуса после действий.

В Л3 данные сохранялись в браузере. В Л4 RTK Query управляет загрузкой, кешем и повтором запросов. Самой сложной частью стало согласование оптимистичных изменений с ответами сервера.

## Проверка

```sh
npm run lint
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

REST- и браузерные тесты запускают собственную временную базу на порту 3001. Перед тестами остановите сервер, если он занимает этот порт. Для отдельной сборки клиента и API задайте адрес доступного учебного сервера через `VITE_API_URL` при сборке.
