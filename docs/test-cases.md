## Приёмка Л4

| № | Сценарий | Ожидаемый результат | Результат |
|---:|---|---|---|
| 1 | Открыть страницу с недоступным API | Сообщение и кнопка «Повторить» | Playwright, сетевой обрыв |
| 2 | Восстановить API и повторить запрос | Данные без перезагрузки | Playwright |
| 3 | Отметить задачу с задержкой 1500 мс | Отметка и счётчик меняются до ответа | REST, реальная задержка |
| 4 | Получить 500 при отметке, правке, добавлении или удалении | Откат кеша и сообщение | REST с `CHAOS_RATE=1` и Playwright |
| 5 | Удалить задачу и отменить через уведомление | Задача и её подзадачи снова на сервере | Playwright |
| 6 | Открыть прежний адрес восстановленной задачи | Открывается карточка | Playwright |
| 7 | Ctrl+Z, затем Ctrl+Shift+Z | Отмена и повтор сохранились после перезагрузки | Playwright |
| 8 | После отмены выполнить новую команду | Повтор прежней команды недоступен | REST |
| 9 | Отменить во время записи, повторно нажать отметку | Действия блокируются до согласования | REST и Playwright |
| 10 | Получить 500 во время отмены | Действие осталось доступно для повторной отмены | REST с `CHAOS_RATE=1` |
| 11 | Нажать Ctrl+Z при наборе текста | Отменяется ввод без изменения задач | Playwright |
| 12 | Выполнить сброс базы | Сервер возвращает начальные данные | Проверка чистого запуска |

Дополнительно проверены прямой и обратный запросы для добавления и правки задач, каждой операции над подзадачами, очистки выполненных и переименования. Удаление списка проверено на каскад и сохранение других списков. Тесты используют отдельную временную базу.

Итоговый прогон в 4lab: ESLint, сборка Vite, два REST-теста и 15 браузерных сценариев в Edge. Отдельно проверены команды `db:reset` и `server:chaos`.
